
# SMART KRISHI ASSISTANT
## Project Report

### 1. Introduction
Smart Krishi Assistant is a web-based prototype that provides
basic crop information and farming guidance through a simple
and user-friendly interface.

### 2. Objectives
- Provide crop information for farmers.
- Help users search for crop information.
- Display basic farming tips.
- Offer English and Kannada interface labels.
- Provide preliminary guidance for common farming questions.

### 3. Technologies Used
- HTML for webpage structure.
- CSS for design and responsive layout.
- JavaScript for interactive features.

### 4. Features
1. Farmer dashboard.
2. Crop information for Ragi, Paddy, and Tomato.
3. Crop search.
4. English and Kannada heading selection.
5. Farming tips.
6. Keyword-based farming question guidance.
7. Mobile-friendly design.

### 5. Testing
The following features were tested:
- Crop information display.
- Crop search.
- Language selection.
- Farming tips display.
- Farming question responses.

### 6. Limitations
The current prototype uses predefined keyword rules.
It does not use a live AI model, weather service, or
agricultural database.

### 7. Future Enhancements
- Expand Kannada translations.
- Add weather information.
- Include expert-reviewed crop guidance.
- Add a database and backend if needed.
- Improve crop disease identification.

### 8. Conclusion
Smart Krishi Assistant demonstrates how HTML, CSS, and
JavaScript can be used to create an interactive farming
information website.
