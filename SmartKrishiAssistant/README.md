
# Smart Krishi Assistant

## Project Overview
Smart Krishi Assistant is a beginner-friendly web application
that provides basic farming information and guidance.

## Features
- Crop information for Ragi, Paddy, and Tomato
- Crop search
- English and Kannada language selector
- Basic farming tips
- Farming question and guidance section
- Responsive, mobile-friendly design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Open the project folder.
2. Open index.html in a web browser.
3. Explore the available features.

## Project Status
Prototype developed for educational purposes.

## Limitation
The farming guidance uses predefined rules and is not an
AI-powered diagnosis or a substitute for agricultural experts.
